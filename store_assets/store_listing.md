## 簡単な説明(80文字以内)

```
行った都道府県を塗りつぶして旅の思い出を記録。6段階ランクとメモ・写真で、あなただけの足跡マップを作ろう。登録不要・完全無料。
```

## 詳しい説明(4000文字以内)

```
■ 日本地図を、思い出で塗りつぶそう

「足跡マップ」は、47都道府県への"行った記録"を日本地図に塗りつぶして残せる旅行記録アプリです。
旅行や出張で訪れた県がどんどん色づいていく達成感を楽しみながら、思い出をメモと写真で保存できます。

■ 6段階のランクで色分け

・居住(5点): 住んだ
・宿泊(4点): 泊まった
・訪問(3点): 歩いた
・接地(2点): 降り立った
・通過(1点): 通過した
・未踏(0点): 行ってない

全県の合計が「足跡スコア」(最高235点)。スコアアップを目指して、次の旅の計画も楽しくなります。

■ 訪問記録を何件でも

県ごとに「いつ・何で行ったか」を記録できます。
・日付
・種別(旅行/出張/帰省/イベント/その他)
・タイトルとメモ
・写真(複数枚OK)

「あの出張で初めて降り立った」「家族旅行で泊まった」など、県との思い出を時系列で振り返れます。

■ 安心設計

・アカウント登録不要、完全無料、広告なし
・データはすべて端末内にのみ保存(外部送信なし)
・JSON形式のバックアップ/復元機能つき(機種変更時も安心)

■ こんな方におすすめ

・47都道府県制覇を目指している方
・旅行や出張の記録を手軽に残したい方
・日本地図が塗りつぶされていくのが好きな方

さあ、あなたの足跡で日本地図を塗りつぶしましょう!

---
日本地図データ: geolonia/japanese-prefectures(MITライセンス)
```
